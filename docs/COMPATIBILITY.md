# Racket版本与Python版本的语法兼容性

## 📊 语法对比

### Python版本语法 vs Racket版本语法

| 功能 | Python版本 | Racket版本 | 兼容性 |
|------|-----------|-----------|--------|
| 变量定义 | `定义变量x为10` | `定 x 是 10` | ❌ 不兼容 |
| 输出 | `输出"内容"` | `输出 "内容"` | ⚠️ 部分兼容 |
| 条件 | `如果x大于5则` | `x 大于 5，输出 "内容"。` | ❌ 不兼容 |
| 循环 | `对于i从1到10：` | `对于 i 从 1 到 10：` | ⚠️ 部分兼容 |

---

## 🔍 详细对比

### 1. 变量定义

**Python版本：**
```言律
定义变量x为10
定义变量y为20
定义变量z为x加y
```

**Racket版本：**
```言律
定 x 是 10
定 y 是 20
定 z 是 x 加 y
```

**差异：**
- Python版本：`定义变量` + 变量名 + `为` + 值
- Racket版本：`定` + 变量名 + `是` + 值

---

### 2. 输出语句

**Python版本：**
```言律
输出"你好世界"
输出x
```

**Racket版本：**
```言律
输出 "你好世界"
输出 x
```

**差异：**
- Python版本：可以不加空格
- Racket版本：建议加空格（无空格版本也支持）

---

### 3. 条件判断

**Python版本：**
```言律
如果x大于5则
    输出"大于5"
否则
    输出"小于等于5"
```

**Racket版本：**
```言律
x 大于 5，输出 "大于5"。
x 小于等于 5，输出 "小于等于5"。
```

**差异：**
- Python版本：传统的if-else结构
- Racket版本：因果链语法

---

### 4. 循环结构

**Python版本：**
```言律
对于i从1到10：
    输出i
```

**Racket版本：**
```言律
对于 i 从 1 到 10：
  输出 i
```

**差异：**
- 基本相同，但Racket版本需要正确的缩进

---

## 🚫 为什么不兼容？

### 技术原因

**1. 实现方式不同**
- Python版本：完整的解释器，支持复杂语法
- Racket版本：基于Racket宏，简化语法

**2. 设计理念不同**
- Python版本：接近传统编程语言
- Racket版本：更自然的中文表达

**3. 解析方式不同**
- Python版本：使用jieba分词，支持复杂语法
- Racket版本：自定义分词，简化实现

---

## ✅ 如何运行旧例子？

### 方案1：转换语法（推荐）

将Python版本的语法转换为Racket版本：

**转换规则：**
```
定义变量x为10  →  定 x 是 10
输出"内容"     →  输出 "内容"
如果x大于5则   →  x 大于 5，输出 "内容"。
```

**示例转换：**

**原文件（Python版本）：**
```言律
定义变量x为10
输出x
定义变量y为20
定义变量z为x加y
输出z
```

**转换后（Racket版本）：**
```言律
定 x 是 10
输出 x
定 y 是 20
定 z 是 x 加 y
输出 z
```

---

### 方案2：创建兼容版本

为每个旧例子创建Racket兼容版本：

**示例：**

**Python版本：** `examples/simple_test.yan`
```言律
定义变量x为10
输出x
```

**Racket版本：** `examples/simple_test_racket.yan`
```言律
定 x 是 10
输出 x
```

---

### 方案3：扩展Racket版本支持

可以扩展Racket版本，使其支持Python版本的语法：

**需要添加：**
- 支持 `定义变量` 关键词
- 支持 `为` 关键词
- 支持 `如果...则...否则` 语法

**但这会增加复杂度。**

**优点：**
- 更简洁
- 更自然
- 性能更好

yanlv 运行 examples/simple_test.yan

## 🔄 转换工具

可以创建一个简单的转换脚本：

**转换规则：**
```python
# 伪代码
text = text.replace("定义变量", "定")
text = text.replace("为", "是")
text = text.replace("如果", "")
text = text.replace("则", "，")
```

**但这只是基础转换，复杂语法需要手动调整。**
