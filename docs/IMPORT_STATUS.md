## 💡 导入库设计

### 语法设计

**方案1: 简单导入**
```言律
导入 "数学库.yan"
导入 "字符串库.yan"
```

**方案2: 选择性导入**
```言律
从 "数学库.yan" 导入 平方根, 绝对值
从 "字符串库.yan" 导入 长度, 连接
```

**方案3: 别名导入**
```言律
导入 "数学库.yan" 为 数学
数学.平方根(16)
```

---

### 实现方案

**1. 库文件格式**

**`数学库.yan`:**
```言律
# 言律数学库

# 导出函数
导出 平方根(赵) 为 赵乘赵
导出 绝对值(赵) 为 赵大于等于0，赵。赵小于0，0减赵。

# 导出变量
导出 圆周率 为 3.14159
```

---

**2. 导入处理**

```racket
;; 解析导入语句
(define (parse-import line-tokens)
  ;; 导入 "文件名.yan"
  (define file-path (extract-file-path line-tokens))
  ;; 加载文件
  (define lib-code (load-library file-path))
  ;; 解析库代码
  (parse-library lib-code))
```

---

**3. 库加载**

```racket
;; 加载库文件
(define (load-library file-path)
  (define source (file->string file-path))
  (define in (open-input-string source))
  (read-syntax file-path in))
```

## 📝 当前替代方案

### 方案1: 直接包含

**方法:** 将库代码直接复制到主文件

**示例:**
```言律
# 主程序

# 库代码（直接包含）
定义宏 平方根(赵) 为 赵乘赵
定义变量 圆周率 为 3.14159

# 主程序代码
输出 平方根(16)
输出 圆周率
```

---

### 方案2: Racket原生导入

**方法:** 使用Racket的require机制

**示例:**
```racket
;; 在Racket层面
(require "math_library.rkt")
```

**优点:**
- 立即可用
- 性能好

**缺点:**
- 不是言律语法
- 需要Racket知识
