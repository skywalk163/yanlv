## ⚠️ 待完善

### 多参数宏 - 50%

**问题:**
- 参数分割逻辑有误
- 两个参数被合并为一个列表

**测试:**
```言律
定义宏 平方和(赵, 钱) 为 赵加钱
输出 平方和(孙, 李)
```

**错误:**
```
list-ref: index too large for list
  index: 1
  in: (list (list (token "李" ...) (token "孙" ...)))
```

**原因:**
- 参数分割后只有一个列表
- 应该是两个独立的列表

---

## 💡 解决方案

### 方案1: 修复参数分割

**问题定位:**
```racket
;; 当前: 参数被合并
(list (token "李" ...) (token "孙" ...))

;; 应该: 两个独立列表
(list (list (token "孙" ...))
      (list (token "李" ...)))
```

**修复方向:**
- 检查逗号分割逻辑
- 确保每个参数独立成列表

---

### 方案2: 简化多参数处理

**思路:**
- 先支持单参数宏（已成功）
- 逐步完善多参数支持
- 确保基础功能稳定
