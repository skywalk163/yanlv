## 🚀 使用方法

### 运行无空格版本

```powershell
racket yanlv_nospace.rkt 文件名.yan
```

### 支持的语法

**1. 无空格变量定义**
```言律
定年龄是25
定姓名是"张三"
定分数是85.5
```

**2. 有空格变量定义（也支持）**
```言律
定 年龄 是 25
定 姓名 是 "张三"
```

**3. 无空格输出**
```言律
输出年龄
输出姓名
输出"你好世界"
```

**4. 无空格因果链**
```言律
分数大于80，输出"良好"。
温度大于28，输出"高温"。
```

**5. 无空格算术运算**
```言律
定a是10
定b是3
输出a加b
输出a减b
```

## 💡 实现原理

### 智能分词算法

**1. 关键词优先匹配**
```racket
;; 按长度降序排列，优先匹配长关键词
(define keywords-sorted
  '("大于等于" "小于等于" "不等于" "为主题"
    "输出" "定义" "变量" ...))
```

**2. 逐字符扫描**
```racket
;; 扫描每个字符
(when (char>=? char #\一)
  ;; 尝试匹配最长关键词
  ;; 如果不匹配，作为标识符
  ...)
```

**3. 边界处理**
```racket
;; 确保不是关键词的开始
(not (is-keyword-start? text pos len))
```
