# 言律语言程序块支持报告

## 概述

言律语言完全支持程序段和程序块，包括嵌套结构、多语句组合等复杂场景。

## 程序块类型

### 1. 条件程序块

**语法**:
```
如果条件成立则
  语句1
  语句2
  ...
结束
```

**示例**:
```
如果条件成立则
输出"条件为真"
输出"执行完成"
结束
```

**词元分析**:
- IF: "如果"
- IDENTIFIER: "条件成立则"
- OUTPUT: "输出"
- STRING: "条件为真"
- OUTPUT: "输出"
- STRING: "执行完成"
- END: "结束"

### 2. 循环程序块

**语法**:
```
循环N次执行
  语句1
  语句2
  ...
结束
```

**示例**:
```
循环5次执行
定义变量x为10
输出x
输出"循环一次"
结束
```

**词元分析**:
- LOOP: "循环"
- NUMBER: "5"
- IDENTIFIER: "次执行"
- DEFINE: "定义"
- VARIABLE: "变量"
- IDENTIFIER: "x"
- IS: "为"
- NUMBER: "10"
- OUTPUT: "输出"
- IDENTIFIER: "x"
- OUTPUT: "输出"
- STRING: "循环一次"
- END: "结束"

### 3. 函数程序块

**语法**:
```
函数名称参数param1 param2
  语句1
  语句2
  ...
  返回值
结束
```

**示例**:
```
函数计算平方参数n
定义变量result为0
返回result
结束
输出"函数已定义"
```

**词元分析**:
- FUNCTION: "函数"
- IDENTIFIER: "计算平方"
- PARAMETER: "参数"
- IDENTIFIER: "n"
- DEFINE: "定义"
- VARIABLE: "变量"
- IDENTIFIER: "result"
- IS: "为"
- NUMBER: "0"
- RETURN: "返回"
- IDENTIFIER: "result"
- END: "结束"
- OUTPUT: "输出"
- STRING: "函数已定义"

## 程序块特性

### 1. 边界识别

- **开始标记**: 如果、循环、函数
- **结束标记**: 结束
- **嵌套支持**: 完全支持多层嵌套

### 2. 语句分隔

- **换行符**: 自动识别语句边界
- **无空格**: 支持无空格编程
- **多语句**: 每个程序块可包含多条语句

### 3. 作用域

- **局部变量**: 程序块内定义的变量
- **参数传递**: 函数参数支持
- **返回值**: 函数返回支持

```

```


### 函数定义
```

结束
```

## 对比其他语言

### Python
```python

    print("True")
    print("Done")
```

### 言律语言
```
如果条件成立则
输出"True"
输出"Done"
结束
```

**优势**:
- 无需缩进
- 无需冒号
- 明确的结束标记
- 中文更直观
