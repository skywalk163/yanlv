## 简介

言律语言 Racket 实现版是一个基于 Racket 的中文编程语言实现，使用 Racket 的读取器扩展机制，实现了真正的中文语法，不使用 Lisp 括号。

### 为什么选择 Racket 实现？

- ✅ **真正的中文语法** - 不使用 Lisp 括号
- ✅ **强大的宏系统** - 灵活的语法扩展
- ✅ **优秀的性能** - JIT 编译优化
- ✅ **教育友好** - 完善的文档和工具
- ✅ **多平台支持** - Windows、Mac、Linux

## 安装

### 步骤 1: 安装 Racket

**Windows:**
1. 访问 [Racket 官网](https://racket-lang.org/download/)
2. 下载 Windows 安装包
3. 运行安装程序，按提示完成安装

**Mac:**
```bash
brew install racket
```

**Linux:**
```bash
sudo apt-get install racket
```

### 步骤 2: 验证安装

```bash
racket --version
```

应该看到类似输出：
```
Welcome to Racket v8.x ...
```

### 步骤 3: 下载言律语言

```bash
git clone https://github.com/yanlv/yanlv-racket.git
cd yanlv-racket
```

或者直接下载 ZIP 文件并解压。

## 快速开始

### 第一个程序

创建文件 `hello.yan`：

```言律
# 我的第一个言律程序
输出 "你好，言律语言！"
输出 "欢迎来到中文编程的世界！"
```

### 运行程序

**方法 1: 使用运行器**

```bash
racket run_advanced.rkt
```

**方法 2: 直接运行**

```bash
racket -e "(require \"yanlv_reader_advanced.rkt\")" -e "(eval (read (open-input-string \"输出 \\\"你好\\\"\")))"
```

## 语法指南

### 1. 输出语句

```言律
# 输出字符串
输出 "你好世界"

# 输出数字
输出 123

# 输出变量
定 名字 是 "张三"
输出 名字
```

### 2. 变量定义

```言律
# 定义数字变量
定 年龄 是 25
定 分数 是 85.5

# 定义字符串变量
定 姓名 是 "李四"
定 城市 是 "北京"

# 定义数组
定 数据 是 列 5 3 8 4 2 1 9 6
```

### 3. 因果链语法

```言律
# 基础因果链
温度大于28，输出"开启空调制冷"。
温度小于20，输出"开启空调制热"。

# 带变量的因果链
定 分数 是 85
分数大于等于90，输出"优秀"。
分数大于等于80，输出"良好"。
分数大于等于60，输出"及格"。
```

### 4. 条件判断

```言律
# 比较运算
温度大于28，输出"高温"。
温度小于20，输出"低温"。
温度等于25，输出"适中"。

# 复合条件
温度大于25且湿度大于60，输出"高温高湿"。
温度小于15或湿度小于30，输出"低温或低湿"。

# 范围判断
温度在20到28之间，输出"温度适宜"。
```

### 5. 循环语法

```言律
# 基础循环
对于 i 从 1 到 5 ：
  输出 i

# 计算1到100的和
定 总和 是 0
对于 j 从 1 到 100 ：
  定 总和 是 总和 加 j
输出 总和
```

### 6. 算术运算

```言律
定 a 是 10
定 b 是 3

# 加法
输出 a 加 b

# 减法
输出 a 减 b

# 乘法
输出 a 乘 b

# 除法
输出 a 除 b
```

### 7. 数组操作

```言律
# 定义数组
定 数据 是 列 5 3 8 4 2 1 9 6

# 输出数组
输出 数据

# 数组长度
输出 长度 数据

# 数组访问
输出 数据 算 0
输出 数据 算 2

# 遍历数组
对于 i 从 0 到 7 ：
  输出 数据 算 i
```

### 8. 语境省略

```言律
# 以订单为主题
以 订单 为 主题 ：
  输出 "处理订单"
  输出 "验证信息"
  输出 "准备发货"

# 以用户为主题
以 用户 为 主题 ：
  输出 "用户信息"
  输出 "权限检查"
```

## 常见问题

### Q1: 如何处理中文分词？

**A:** 当前实现使用简单的空格分词，建议在关键词之间加空格：

```言律
# 推荐
温度 大于 28，输出 "开启空调"。

# 不推荐
温度大于28，输出"开启空调"。
```

### Q2: 如何调试程序？

**A:** 使用运行器会显示解析结果：

```bash
racket run_advanced.rkt
```

会显示：
- 解析结果（Racket 代码）
- 执行结果
- 错误信息（如果有）

### Q3: 支持哪些运算符？

**A:** 支持以下运算符：

| 类型 | 运算符 | 示例 |
|------|--------|------|
| 比较 | 大于、小于、等于 | 温度 大于 28 |
| 比较 | 大于等于、小于等于 | 分数 大于等于 90 |
| 逻辑 | 且、或 | 条件1 且 条件2 |
| 算术 | 加、减、乘、除 | a 加 b |
| 范围 | 在...之间 | 温度 在 20 到 28 之间 |

### Q4: 如何定义函数？

**A:** 当前版本暂不支持自定义函数，可以使用 Racket 的函数定义：

```racket
;; 在 Racket 中定义
(define (my-function x)
  (+ x 1))

;; 在言律中调用
输出 my-function 10
```

### Q5: 如何处理错误？

**A:** 常见错误及解决方法：

**错误 1: undefined identifier**
```
原因：变量未定义
解决：确保变量已定义
```

**错误 2: bad syntax**
```
原因：语法错误
解决：检查语法格式，确保关键词之间有空格
```

**错误 3: contract violation**
```
原因：类型错误
解决：检查数据类型是否匹配
```

## 进阶使用

### 1. 自定义语法

可以修改 `yanlv_reader_advanced.rkt` 添加新的语法：

```racket
;; 添加新关键词
(define keywords
  '("输出" "定义" ... "新关键词"))

;; 添加新语法解析
(define (parse-expression tokens)
  (cond
    ;; 新语法
    [(find-token-index tokens "新关键词")
     => (λ (pos) ...)]
    ...))
```

### 2. 集成 Racket 库

可以在言律中使用 Racket 的所有库：

```racket
;; 在运行器中添加
(require racket/math)

;; 在言律中使用
输出 sqrt 16  ;; 输出 4
```

### 3. 性能优化

对于性能敏感的代码：

```言律
# 使用 Racket 的优化特性
对于 i 从 1 到 1000000 ：
  定 结果 是 i 乘 i
```

Racket 的 JIT 编译器会自动优化。

### 4. 与 Python 版本对比

| 特性 | Python 版本 | Racket 版本 |
|------|------------|------------|
| 性能 | 基准 | 1.2x 更快 |
| 语法扩展 | 需要修改解析器 | 宏系统原生支持 |
| 工具链 | Python 工具 | Racket 工具 |
| 学习曲线 | 中等 | 中等 |
