## 🚀 使用方法

### REPL (交互模式)

**启动：**
```powershell
racket yanlv_repl.rkt
```

**使用示例：**
```
言律> 定义变量赵为10
言律> 输出赵
10
言律> 定义变量钱为20
言律> 输出 赵加钱
30
言律> :help      # 显示帮助
言律> :clear     # 清空环境
言律> :quit      # 退出
```

---

### Playground (Web界面)

**启动：**
```powershell
racket yanlv_playground.rkt
```

**访问：**
```
http://localhost:8080
```

**使用：**
1. 在代码编辑器中输入言律代码
2. 点击"🚀 运行代码"按钮
3. 在右侧查看执行结果

**示例代码：**
```
定义变量赵为10
定义变量钱为20
输出 赵加钱
```

**结果：**
```
30
```

## 📝 注意事项

### REPL

1. **输入方式**
   - 直接输入代码
   - 按回车执行

2. **命令**
   - `:help` - 显示帮助
   - `:clear` - 清空环境
   - `:quit` - 退出

3. **退出**
   - 输入 `:quit`
   - 或按 `Ctrl+D` (Linux/Mac)
   - 或按 `Ctrl+Z` (Windows)

---

### Playground

1. **端口**
   - 默认: 8080
   - 可指定: `racket yanlv_playground.rkt 3000`

2. **访问**
   - 本地: `http://localhost:8080`
   - 局域网: `http://你的IP:8080`

3. **停止**
   - 按 `Ctrl+C`
