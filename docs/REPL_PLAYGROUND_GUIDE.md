# Racket版交互模式和Playground使用指南

## 🎯 概述

Racket版现在有完整的交互模式和Playground！

---

## 1️⃣ 交互模式 (REPL)

### 启动交互模式

```powershell
racket yanlv_repl.rkt
```

### 界面

```
╔════════════════════════════════════════════════╗
║     言律语言交互模式 v6.0 (REPL)              ║
╚════════════════════════════════════════════════╝

✨ 特性：
  • 实时输入执行
  • 即时反馈结果
  • 支持Python和Racket两种语法
  • 使用百家姓作为变量名

📝 示例：
  言律> 定义变量赵为10
  言律> 输出赵
  10
  言律> 定 钱是20
  言律> 输出 赵加钱
  30

💡 命令：
  :help    - 显示帮助
  :clear   - 清空环境
  :vars    - 显示变量
  :quit    - 退出

🎯 开始输入言律代码吧！
```

---

### 使用示例

**1. 变量定义**

```
言律> 定义变量赵为10
言律> 输出赵
10
```

**2. 运算**

```
言律> 定义变量钱为20
言律> 输出 赵加钱
30
言律> 输出 赵减钱
-10
```

**3. 条件判断**

```
言律> 定义变量孙为90
言律> 孙 大于 80，输出 "优秀"。
优秀
```

**4. 混合语法**

```
言律> 定义变量李为100      # Python语法
言律> 定 周是200           # Racket语法
言律> 输出 李加周
300
```

---

### 内置命令

**`:help` - 显示帮助**
```
言律> :help

╔════════════════════════════════════════════════╗
║              言律语言帮助文档                  ║
╚════════════════════════════════════════════════╝

📖 语法说明：

1. 变量定义：
   Python版本：定义变量赵为10
   Racket版本：定 钱是20

2. 输出：
   输出 赵
   输出 "你好世界"

3. 运算：
   输出 赵加钱
   输出 赵减钱

4. 条件：
   赵大于10，输出 "大于10"。
```

**`:vars` - 显示变量**
```
言律> :vars

📊 当前变量：
─────────────────────────────────────
  赵 = 10
  钱 = 20
  孙 = 30
```

**`:clear` - 清空环境**
```
言律> :clear
✅ 环境已清空
```

**`:quit` - 退出**
```
言律> :quit

再见！👋
```

## 2️⃣ Playground (Web界面)

### 启动Playground

```powershell
racket yanlv_playground.rkt
```

或指定端口：

```powershell
racket yanlv_playground.rkt 3000
```

---

### 启动信息

```
╔════════════════════════════════════════════════╗
║     言律语言 Playground v6.0                  ║
╚════════════════════════════════════════════════╝

🌐 服务器启动中...
📍 访问地址: http://localhost:8080

✨ 特性：
  • 在浏览器中运行言律代码
  • 实时执行和反馈
  • 精美的界面设计
  • 内置示例代码

💡 按 Ctrl+C 停止服务器
```

---

### Web界面特性

**1. 精美设计**
- 渐变背景
- 现代化UI
- 响应式布局

**2. 代码编辑器**
- 语法高亮
- 自动缩进
- 实时编辑

**3. 执行结果**
- 即时反馈
- 错误提示
- 格式化输出

**4. 内置示例**
- Hello World
- 变量计算
- 条件判断

---

### 使用流程

**1. 启动服务器**
```powershell
racket yanlv_playground.rkt
```

**2. 打开浏览器**
```
http://localhost:8080
```

**3. 输入代码**
```
定义变量赵为10
定义变量钱为20
输出 赵加钱
```

**4. 点击运行**
```
🚀 运行代码
```

**5. 查看结果**
```
30
```
