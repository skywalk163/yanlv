### 4. 实用示例 ✅

**创建的示例：**

**1. 计算器示例** (`examples/calculator.yan`)
```言律
定 x 是 100
定 y 是 25
输出 x 加 y
输出 x 减 y
输出 x 乘 y
输出 x 除 y
```

**2. 成绩管理系统** (`examples/grade_system.yan`)
```言律
定 数学 是 85
定 英语 是 92
定 物理 是 78
定 总分 是 数学 加 英语 加 物理
定 平均分 是 总分 除 3
平均分 大于等于 90，输出 "优秀"。
```

**3. 智能家居控制** (`examples/smart_home.yan`)
```言律
定 温度 是 28
定 湿度 是 65
温度 大于 28，输出 "开启空调制冷"。
湿度 大于 70，输出 "开启除湿机"。
```

**4. 数据处理** (`examples/data_process.yan`)
```言律
定 数据1 是 10
定 数据2 是 20
定 总和 是 数据1 加 数据2
输出 总和
```

## 🚀 可用的运行器

### 1. 基础版本
```powershell
racket yanlv.rkt 文件名.yan
```
- 稳定可靠
- 支持有空格语法

### 2. 无空格版本
```powershell
racket yanlv_nospace.rkt 文件名.yan
```
- 支持无空格语法
- 支持混合写法

### 3. 增强版本（推荐）
```powershell
racket yanlv_enhanced.rkt 文件名.yan
```
- 友好的错误提示
- 详细的执行信息
- 最稳定
