# 言律语言 Racket 版使用指南

## 🚀 5分钟快速上手

### 第一步：确认环境

打开命令行，输入：
```bash
racket --version
```

看到版本信息说明 Racket 已安装成功。

### 第二步：运行第一个程序

**方法1：使用批处理脚本（Windows）**
```bash
run_yanlv.bat quick_start.yan
```

**方法2：直接使用 Racket**
```bash
racket run_advanced.rkt
```

### 第三步：查看结果

你会看到：
```

║   言律语言高级语法执行器 v3.0      ║
╚══════════════════════════════════════╝

📄 文件: quick_start.yan

⚡ 执行结果:
─────────────────────────────────────
你好，言律语言！
这是 Racket 实现版本
姓名：
张三

25
...
```

## 💡 实用技巧

### 技巧1：关键词之间加空格

```言律
# ✅ 正确
温度 大于 28，输出 "高温"。

# ❌ 错误
温度大于28，输出"高温"。
```

### 技巧2：使用注释

```言律
# 这是单行注释
输出 "代码"  # 行尾注释
```

### 技巧3：缩进很重要

```言律
# 循环体需要缩进
对于 i 从 1 到 5 ：
  输出 i  # 缩进2个空格
```

### 技巧4：句号结束语句

```言律
# 因果链用句号结束
条件，动作。

# 变量定义用句号结束
定 x 是 10。
```

## 🔧 常见问题解决

### 问题1：找不到文件

**错误：**
```
文件: test.yan not found
```

**解决：**
- 检查文件路径是否正确
- 确保文件在当前目录

### 问题2：语法错误

**错误：**
```
bad syntax
```

**解决：**
- 检查关键词之间是否有空格
- 检查标点符号是否正确
- 检查缩进是否正确

### 问题3：变量未定义

**错误：**
```
undefined identifier
```

**解决：**
- 确保变量已定义
- 检查变量名拼写

## 🌟 最佳实践

### 1. 代码风格

```言律
# ✅ 推荐：清晰的代码风格
定 温度 是 30

温度 大于 28，输出 "高温"。
温度 小于 20，输出 "低温"。

# ❌ 不推荐：紧凑的代码风格
定温度是30
温度大于28，输出"高温"。
```

```言律
# ✅ 使用有意义的变量名

定 考试分数 是 85

# ❌ 使用无意义的变量名
定 x 是 "张三"
定 y 是 85
```

```言律
# 功能：学生成绩管理

# 定义学生信息

# 判断成绩等级
分数 大于等于 90，输出 "优秀"。
```
