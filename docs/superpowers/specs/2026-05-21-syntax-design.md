## 1. 设计原则

### 1.1 核心原则

言律语言的语法设计遵循以下核心原则：

#### 原则1：明确的分词边界

**问题：** 贪心最长匹配可能导致歧义

**解决方案：**
- 使用 THULAC 进行分词和词性标注
- 保留元数驱动解析机制
- 支持空格分隔（可选）

**示例：**
```yan
# 无空格（依赖THULAC分词）
印斐波那契。

# 有空格（明确分隔）
印 斐波那契。

# THULAC分词结果
[('印', 'v'), ('斐波那契', 'n')]
# 词性：v=动词，n=名词
```

---

#### 原则2：关键字保护机制

**问题：** 关键字可能与用户定义冲突

**解决方案：**
- 关键字有独立的命名空间
- 上下文感知关键字含义
- 提供转义机制

**示例：**
```yan
# "是"作为关键字
定名称是"张三"。

# "是"作为变量名（使用转义符）
定\是等于真。

# 上下文感知
用户是否VIP？  # "是否"是疑问式关键字
用户·是否等于真。  # "是否"是属性名
```

---

#### 原则3：统一的属性访问语法

**问题：** 属性访问方式多样，容易混淆

**解决方案：**
- 统一使用 `·` 作为属性访问符
- 支持链式访问
- 提供语法糖

**示例：**
```yan
# 标准写法
用户·姓名

# 链式访问
用户·地址·城市

# 语法糖（自动转换）
用户的姓名  →  用户·姓名
用户的地址的城市  →  用户·地址·城市
```

---

#### 原则4：明确的运算符定义

**问题：** 运算符优先级不明确

**解决方案：**
- 明确定义所有运算符的优先级和结合性
- 口语化运算符有明确语义
- 支持组合条件

**示例：**
```yan
# 比较运算符
分数大于90
分数小于60
分数等于100

# 组合条件
分数大于60且分数小于90
用户是VIP或订单金额大于10000
```

---

#### 原则5：灵活的动词元数

**问题：** 动词元数固定，不够灵活

**解决方案：**
- 动词有默认元数
- 支持可变参数
- 支持可选参数

**示例：**
```yan
# 固定元数
印"你好"。  # 元数=1

# 可变参数
定求和是函……参数：
  参数，归加0。

求和1、2、3、4、5。

# 可选参数
定发送邮件是函收件人、主题、内容="无内容"：
  发送。
```

---

#### 原则6：缩进定义块结构

**问题：** 显式"结束"不符合中文习惯

**解决方案：**
- 缩进定义块
- 支持单行语法
- 支持混合使用

**示例：**
```yan
# 多行块（缩进定义）
若分数大于90：
  印"优秀"。
  发送奖励。

# 单行块
若分数大于90就印"优秀"。

# 混合使用
若分数大于90：
  若用户是VIP：
    印"优秀VIP"。
  不然：
    印"优秀"。
```

---

#### 原则7：明确的作用域规则

**问题：** 作用域规则复杂，容易出错

**解决方案：**
- 词法作用域
- 闭包支持
- 递归支持

**示例：**
```yan
# 词法作用域
定x是10。
若真：
  定x是20。  # 块内新变量
  印x。     # 输出：20
印x。       # 输出：10

# 闭包
定计数器是函：
  定n是0。
  回函n加等于1。

# 递归
定阶乘是函n：
  若n等于0就回1。
  回n乘以阶乘n减1。
```

---

#### 原则8：渐进式类型系统

**问题：** 动态类型容易出错

**解决方案：**
- 动态类型为基础
- 类型注解可选
- 类型推断

**示例：**
```yan
# 动态类型
定x是"10"。
x加5。  # 运行时错误

# 类型注解
定x是数："10"。
x加5。  # 编译时警告

# 类型推断
定x是10。  # 推断为数字
定y是"hello"。  # 推断为字符串
```

### 1.2 设计决策表

| 问题 | 言语言方案 | zhixing方案 | 言律方案 | 理由 |
|------|-----------|------------|---------|------|
| 分词方式 | 元数驱动 | 贪心最长匹配 | THULAC分词 + 元数驱动 | 更准确，更可扩展 |
| 关键字冲突 | 固定关键字集合 | 贪心匹配 | 关键字命名空间 + 上下文感知 | 避免冲突，更灵活 |
| 属性访问 | `·` | `·` | `·` + 语法糖 | 统一且灵活 |
| 运算符优先级 | 动词 | 动词 | 明确的优先级表 | 更清晰 |
| 动词元数 | 固定 | 吞噬 | 固定 + 可变 + 可选 | 更灵活 |
| 块结构 | `：` + `。` | 缩进 | 缩进 + 单行 | 符合中文习惯 |
| 作用域 | 同一命名空间 | 词法作用域 | 词法作用域 | 更安全 |
| 类型系统 | 动态类型 | 动态类型 | 动态 + 可选注解 | 渐进式 |

## 2. 词法规范

### 2.1 字符集

言律使用以下字符集：

**基本字符：**
- 中文字符（U+4E00 - U+9FFF）
- 英文字母（A-Z, a-z）
- 数字（0-9）
- 下划线（_）

**标点符号：**
- `。` - 句号（语句终止符）
- `，` - 逗号（管道操作符）
- `；` - 分号（并列分隔符）
- `：` - 冒号（作用域入口标记）
- `、` - 顿号（参数分隔符）
- `'` `'` - 单引号（字符串字面量）
- `"` `"` - 双引号（字符串字面量，支持转义）
- `！` - 叹号（断言/强调）
- `？` - 问号（条件判断）
- `《》` - 书名号（模块/文件名）
- `……` - 省略号（可变参数/范围）
- `——` - 破折号（标签/标记）
- `～` - 波浪号（范围/约数）
- `·` - 间隔号（属性访问）
- `【】` - 方括号（索引/标注）
- `①②③` - 圆圈号（步骤标记）

**运算符：**
- `+` `-` `*` `/` `%` - 算术运算符
- `=` - 赋值运算符
- `>` `<` `>=` `<=` `==` `!=` - 比较运算符
- `(` `)` - 分组

**特殊符号：**
- `{{` `}}` - Python代码块
- `[[` `]]` - JavaScript代码块
- `<<<` `>>>` - SQL代码块
- `$(` `)` - 数学表达式

### 2.3 分词规则

#### 2.3.1 分词优先级

优先级从高到低：

| 优先级 | 类型 | 规则 | 示例 |
|:---:|------|------|------|
| 1 | `QUOTE` | 引号包围，整体提取 | `"你好"` `'世界'` |
| 2 | `MATH` | `$(...)` 包围，整体提取 | `$(1+2*3)` |
| 3 | `PYTHON` | `{{...}}` 包围，整体提取 | `{{import os}}` |
| 4 | `JAVASCRIPT` | `[[...]]` 包围，整体提取 | `[[alert(1)]]` |
| 5 | `SQL` | `<<<...>>>` 包围，整体提取 | `<<<SELECT *>>>` |
| 6 | `NUM` | 连续数字+小数点 | `123` `3.14` `-5` |
| 7 | `BOOL` | 布尔值关键字 | `真` `假` |
| 8 | `KEYWORD` | 关键字（THULAC + 字典） | `若` `则` `不然` |
| 9 | `VERB` | 动词（THULAC词性标注） | `印` `加` `乘` |
| 10 | `IDENT` | 标识符（汉字+字母+数字） | `用户` `name` `x1` |
| 11 | `OPERATOR` | 运算符 | `+` `-` `*` `/` |
| 12 | `STRUCT` | 结构符 | `。` `，` `；` `：` `、` |
| 13 | `SPACE` | 空白符，直接丢弃 | ` ` `\t` `\n` |

#### 2.3.2 THULAC 分词流程

```python
import thulac

class YanLVLexer:
    def __init__(self):
        # 初始化 THULAC
        self.thu = thulac.thulac()
        
        # 添加自定义词汇
        self._add_custom_words()
    
    def _add_custom_words(self):
        """添加言律语言专用词汇"""
        custom_words = [
            # 关键字
            ('若', 'c'),      # 连词
            ('则', 'c'),      # 连词
            ('不然', 'c'),    # 连词
            ('就', 'c'),      # 连词
            ('定', 'v'),      # 动词
            ('函', 'n'),      # 名词
            ('回', 'v'),      # 动词
            ('印', 'v'),      # 动词
            
            # 运算符
            ('加', 'v'),      # 动词
            ('减', 'v'),      # 动词
            ('乘', 'v'),      # 动词
            ('除', 'v'),      # 动词
            ('大于', 'v'),    # 动词
            ('小于', 'v'),    # 动词
            ('等于', 'v'),    # 动词
            
            # 口语化关键字
            ('如果', 'c'),    # 连词
            ('建议', 'v'),    # 动词
            ('第一步', 'm'),  # 数词
            ('是否', 'v'),    # 动词
            ('时', 'n'),      # 名词
            ('太好了', 'e'),  # 叹词
            ('假设', 'v'),    # 动词
            ('那么', 'c'),    # 连词
            ('只要', 'c'),    # 连词
            ('只有', 'c'),    # 连词
            ('即使', 'c'),    # 连词
            ('虽然', 'c'),    # 连词
            ('不仅', 'c'),    # 连词
            ('而且', 'c'),    # 连词
        ]
        
        for word, pos in custom_words:
            self.thu.add_word(word, pos)
    
    def tokenize(self, text):
        """分词和词性标注"""
        # THULAC 分词
        tokens = self.thu.cut(text)
        
        # 转换为言律 Token
        result = []
        for word, pos in tokens:
            token = self._convert_to_token(word, pos)
            result.append(token)
        
        return result
    
    def _convert_to_token(self, word, pos):
        """将 THULAC 结果转换为言律 Token"""
        # 词性映射
        pos_map = {
            'c': 'KEYWORD',   # 连词 → 关键字
            'v': 'VERB',      # 动词 → 动词
            'n': 'IDENT',     # 名词 → 标识符
            'm': 'NUM',       # 数词 → 数字
            'e': 'KEYWORD',   # 叹词 → 关键字
        }
        
        token_type = pos_map.get(pos, 'IDENT')
        
        return {
            'type': token_type,
            'value': word,
            'pos': pos,
        }
```

### 2.5 标识符规则

#### 2.5.1 标识符命名规范

**允许的字符：**
- 中文字符（U+4E00 - U+9FFF）
- 英文字母（a-z, A-Z）
- 数字（0-9，不能开头）
- 下划线（_）

**命名规范：**
- 变量名：使用中文名称，如 `用户名`、`订单数量`
- 函数名：使用动词+名词，如 `计算面积`、`处理订单`
- 类型名：使用名词，如 `用户`、`订单`

**示例：**
```yan
# 合法标识符
用户名
userName
用户1
_user

# 非法标识符
123用户    # 数字开头
用户-名    # 包含非法字符
```

---

#### 2.5.2 百家姓变量命名

言律支持使用百家姓作为变量名，增加代码的可读性和趣味性。

**示例：**
```yan
定张三是典姓名是"张三"、年龄是25。
定李四是典姓名是"李四"、年龄是30。

张三、李四，比较年龄。
```

```python
class YanLVLexer:
    def tokenize(self, text):
        # 1. 预处理（移除注释）
        text = self._remove_comments(text)
        
        # 2. THULAC 分词
        tokens = self.thu.cut(text)
        
        # 3. 转换为言律 Token
        result = []
        for word, pos in tokens:
            token = self._convert_to_token(word, pos)
            result.append(token)
        
        # 4. 后处理（合并多字运算符）
        result = self._post_process(result)
        
        return result
```

```python
    # 算术动词
```

#### 5.2.2 解析算法

```python
class YanLVParser:
    def parse_verb_call(self, verb_token):
        """解析动词调用"""
        verb = verb_token['value']
        arity = VERB_ARITY.get(verb, 1)
        
        # 收集参数
        args = []
        
        if arity == -1:
            # 可变参数：收集到遇到阻断符
            while not self.is_blocker():
                arg = self.parse_expression()
                args.append(arg)
        else:
            # 固定参数：收集指定数量
            for _ in range(arity):
                arg = self.parse_expression()
                args.append(arg)
        
        return {
            'type': 'Call',
            'verb': verb,
            'args': args,
        }
```

```python
def first_pass(tokens):
    """收集所有用户定义的函数名"""
    definitions = set()
    
    i = 0
    while i < len(tokens):
        token = tokens[i]
        
        # 检测函数定义
        if token['value'] == '定':
            # 查找函数定义
            if i + 2 < len(tokens) and tokens[i + 2]['value'] == '函':
                func_name = tokens[i + 1]['value']
                definitions.add(func_name)
        
        i += 1
    
    return definitions
```

## 6. 常见问题与解决方案

### 6.1 分词歧义

**问题：**
```yan
印斐波那契。
```

**可能歧义：**
- `印` + `斐波那契`（动词 + 参数）
- `印斐波那契`（单个标识符）

**解决方案：**
1. THULAC 分词识别 `印` 为动词
2. 元数驱动解析收集参数
3. 如果用户想定义变量 `印斐波那契`，需要使用转义：
   ```yan
   定\印斐波那契是值。
   ```

---

### 6.2 关键字冲突

**问题：**
```yan
定是是真。
```

**可能歧义：**
- `定` + `是` + `是` + `真`（定义变量 `是` 为 `真`）
- 语法错误

**解决方案：**
1. 使用转义符：
   ```yan
   定\是是真。
   ```
2. 或使用不同的变量名：
   ```yan
   定正确是真。
   ```

---

## 9. 总结

### 9.1 核心设计决策

1. **THULAC分词 + 元数驱动**：准确且可扩展

6. **缩进定义块**：符合中文习惯
7. **词法作用域**：更安全
8. **渐进式类型**：动态 + 可选注解
