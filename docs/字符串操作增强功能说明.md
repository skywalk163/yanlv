# 言律语言字符串操作增强功能说明

## 概述

本次更新为言律语言新增了9个字符串操作功能，大大增强了字符串处理能力。

## 新增功能列表

### 1. 字符串连接 (连接)

**语法：**
```
连接 元素1 元素2 ... [为 目标变量]
```

**功能：** 将多个字符串、数字或变量连接成一个字符串。

**示例：**
```yan
定义变量问候为"你好"
定义变量世界为"世界"
连接 问候 世界                    # 输出: "你好世界"

定义变量数字为123
连接 "数字：" 数字               # 输出: "数字：123.0"

连接 问候 " " 世界 为 结果       # 结果 = "你好 世界"
```

**特点：**
- 支持多个元素连接
- 自动类型转换（数字转字符串）
- 可选的目标变量赋值
- 正确处理中文字符

---

### 2. 字符串切片 (切片)

**语法：**
```
切片 字符串变量 起始位置 [结束位置 [步长]]
```

**功能：** 对字符串进行切片操作，支持负索引和步长。

**示例：**
```yan
定义变量文本为"你好世界"
切片 文本 0 2                    # 输出: "你好"
切片 文本 -2                     # 输出: "世界"
切片 文本 0 4 2                  # 输出: "你世"
```

**特点：**
- 支持负索引（从末尾计算）
- 支持步长参数
- 省略结束位置时切片到末尾
- 正确处理中文字符

---

### 3. 查找全部 (查找全部)

**语法：**
```
查找全部 字符串变量 子串
```

**功能：** 查找子串在字符串中所有出现的位置，返回位置数组。

**示例：**
```yan
定义变量文本为"你好世界你好"
查找全部 文本 "你好"              # 输出: [0, 4]
查找全部 文本 "不存在"            # 输出: []
```

**特点：**
- 返回所有匹配位置
- 未找到时返回空数组
- 正确处理中文字符

---

### 4. 单次替换 (替换一次)

**语法：**
```
替换一次 字符串变量 旧子串 新子串
```

**功能：** 只替换第一个匹配的子串。

**示例：**
```yan
定义变量文本为"你好世界你好"
替换一次 文本 "你好" "您好"       # 文本 = "您好世界你好"
```

**特点：**
- 只替换第一个匹配项
- 保留其他匹配项不变
- 更新原变量值
- 正确处理中文字符

---

### 5. 大写转换 (大写)

**语法：**
```
大写 字符串变量
```

**功能：** 将字符串中的英文字母转换为大写。

**示例：**
```yan
定义变量文本为"Hello世界"
大写 文本                        # 文本 = "HELLO世界"
```

**特点：**
- 只转换英文字母
- 中文字符保持不变
- 更新原变量值

---

### 6. 小写转换 (小写)

**语法：**
```
小写 字符串变量
```

**功能：** 将字符串中的英文字母转换为小写。

**示例：**
```yan
定义变量文本为"HELLO世界"
小写 文本                        # 文本 = "hello世界"
```

**特点：**
- 只转换英文字母
- 中文字符保持不变
- 更新原变量值

---

### 7. 去除首尾空格 (去空格)

**语法：**
```
去空格 字符串变量
```

**功能：** 去除字符串首尾的空白字符。

**示例：**
```yan
定义变量文本为"  你好 世界  "
去空格 文本                      # 文本 = "你好 世界"
```

**特点：**
- 只去除首尾空格
- 保留内部空格
- 更新原变量值

---

### 8. 去除所有空格 (去全部空格)

**语法：**
```
去全部空格 字符串变量
```

**功能：** 去除字符串中的所有空白字符。

**示例：**
```yan
定义变量文本为"  你好 世界  "
去全部空格 文本                  # 文本 = "你好世界"
```

**特点：**
- 去除所有空格、制表符、换行符
- 更新原变量值

---

### 9. 字符遍历 (遍历字符)

**语法：**
```
遍历字符 字符串变量 循环变量
    循环体
结束
```

**功能：** 遍历字符串的每个字符，对每个字符执行循环体。

**示例：**
```yan
定义变量文本为"你好"
遍历字符 文本 字符
    输出 字符
结束
# 输出: "你" "好"
```

**特点：**
- 逐个字符遍历
- 正确处理中文字符
- 支持在循环体中操作字符

## 使用建议

1. **变量命名**：建议使用中文变量名，避免与数字混合（如使用"问候"而不是"s1"）
2. **字符串字面量**：使用双引号包裹字符串，如 `"你好"`
3. **负索引**：切片时支持负索引，-1表示最后一个字符
4. **类型转换**：连接操作会自动将数字转换为字符串
