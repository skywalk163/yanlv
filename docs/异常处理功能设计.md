# 言律语言异常处理功能设计

## 概述

为言律语言添加异常处理机制，支持try-catch语法、自定义异常和异常传播。

---

## 语法设计

### 1. Try-Catch语法

#### 基本语法

```yan
尝试
    可能出错的代码
捕获 异常类型 为 异常变量
    处理异常的代码
结束
```

#### 示例

```yan
尝试
    定义变量结果为 10 除以 0
捕获 "除零错误" 为 错误
    输出 "发生错误："
    输出 错误
结束
```

---

### 2. 多重捕获

```yan
尝试
    可能出错的代码
捕获 "除零错误" 为 错误
    输出 "除零错误"
捕获 "文件错误" 为 错误
    输出 "文件错误"
捕获 "所有" 为 错误
    输出 "其他错误"
结束
```

---

### 3. 抛出异常

```yan
定义变量年龄为 -5
如果 年龄 小于 0 则
    抛出 "年龄不能为负数"
结束
```

---

### 4. 自定义异常

```yan
定义异常 "自定义错误" 消息 "这是一个自定义错误"
抛出 "自定义错误"
```

## TokenType设计

```python
# 异常处理
TRY = "TRY"              # 尝试
CATCH = "CATCH"          # 捕获
THROW = "THROW"          # 抛出
EXCEPTION = "EXCEPTION"  # 异常
FINALLY = "FINALLY"      # 最终（可选）
```

## 内置异常类型

### 1. 除零错误 (DivisionByZeroError)
- 当除数为0时抛出

### 2. 文件错误 (FileError)
- 文件操作失败时抛出

### 3. 类型错误 (TypeError)
- 类型不匹配时抛出

### 4. 索引错误 (IndexError)
- 数组索引越界时抛出

### 5. 变量错误 (VariableError)
- 变量未定义时抛出

---

## 实现要点

### 1. 异常上下文
- 维护异常栈
- 记录异常发生位置
- 保存异常消息

### 2. 异常传播
- 向上传播到调用栈
- 直到找到匹配的catch块
- 如果未捕获，程序终止

### 3. 异常处理流程
```
1. 进入try块
2. 执行try块中的代码
3. 如果发生异常：
   a. 查找匹配的catch块
   b. 执行catch块中的代码
   c. 继续执行try-catch之后的代码
4. 如果没有异常：
   a. 跳过catch块
   b. 继续执行try-catch之后的代码
```

## 使用示例

### 示例1：基本异常处理

```yan
尝试
    定义变量x为 10
    定义变量y为 0
    定义变量结果为 x 除以 y
捕获 "除零错误" 为 错误
    输出 "不能除以零"
    定义变量结果为 0
结束
输出 结果
```

### 示例2：文件操作异常

```yan
尝试
    读取文件 "不存在的文件.txt" 为 内容
捕获 "文件错误" 为 错误
    输出 "文件读取失败"
    定义变量内容为 "默认内容"
结束
输出 内容
```

### 示例3：主动抛出异常

```yan
定义函数 检查年龄 参数 年龄
    如果 年龄 小于 0 则
        抛出 "年龄不能为负数"
    结束
    如果 年龄 大于 150 则
        抛出 "年龄不合理"
    结束
    输出 "年龄有效"
结束

尝试
    调用 检查年龄 参数 -10
捕获 "所有" 为 错误
    输出 错误
结束
```
