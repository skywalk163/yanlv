# 言律语言扩展数学函数说明

## 概述

本次更新为言律语言新增了10个数学函数，大大增强了数学计算能力。

---

## 新增函数列表

### 1. 三角函数

#### 1.1 正弦函数 (正弦)

**语法：**
```
正弦 角度值
```

**功能：** 计算角度的正弦值（弧度制）。

**示例：**
```yan
定义变量角度为1.5708
正弦 角度                    # 输出: 1.0 (约等于sin(π/2))
```

---

#### 1.2 余弦函数 (余弦)

**语法：**
```
余弦 角度值
```

**功能：** 计算角度的余弦值（弧度制）。

**示例：**
```yan
定义变量角度为0
余弦 角度                    # 输出: 1.0
```

---

#### 1.3 正切函数 (正切)

**语法：**
```
正切 角度值
```

**功能：** 计算角度的正切值（弧度制）。

**示例：**
```yan
定义变量角度为0.785398
正切 角度                    # 输出: 1.0 (约等于tan(π/4))
```

---

### 2. 对数函数

#### 2.1 自然对数 (自然对数)

**语法：**
```
自然对数 数值
```

**功能：** 计算以e为底的对数（ln）。

**示例：**
```yan
定义变量数值为2.71828
自然对数 数值                # 输出: 1.0 (约等于ln(e))
```

**注意：** 参数必须大于0。

---

#### 2.2 常用对数 (常用对数)

**语法：**
```
常用对数 数值
```

**功能：** 计算以10为底的对数（log₁₀）。

**示例：**
```yan
定义变量数值为100
常用对数 数值                # 输出: 2.0
```

**注意：** 参数必须大于0。

---

#### 2.3 指数函数 (指数)

**语法：**
```
指数 数值
```

**功能：** 计算e的指定次幂（eˣ）。

**示例：**
```yan
定义变量数值为1
指数 数值                    # 输出: 2.71828... (约等于e)
```

---

### 3. 取整函数

#### 3.1 向上取整 (向上取整)

**语法：**
```
向上取整 数值
```

**功能：** 返回大于或等于参数的最小整数。

**示例：**
```yan
定义变量数值为3.2
向上取整 数值                # 输出: 4

定义变量负数为-2.3
向上取整 负数                # 输出: -2
```

---

#### 3.2 向下取整 (向下取整)

**语法：**
```
向下取整 数值
```

**功能：** 返回小于或等于参数的最大整数。

**示例：**
```yan
定义变量数值为3.8
向下取整 数值                # 输出: 3

定义变量负数为-2.3
向下取整 负数                # 输出: -3
```

---

#### 3.3 四舍五入 (四舍五入)

**语法：**
```
四舍五入 数值
```

**功能：** 对数值进行四舍五入。

**示例：**
```yan
定义变量数值为3.5
四舍五入 数值                # 输出: 4

定义变量数值为3.4
四舍五入 数值                # 输出: 3
```

---

### 4. 阶乘函数 (阶乘)

**语法：**
```
阶乘 整数
```

**功能：** 计算非负整数的阶乘。

**示例：**
```yan
定义变量数值为5
阶乘 数值                    # 输出: 120 (5! = 5×4×3×2×1)

阶乘 0                       # 输出: 1 (0! = 1)
```

**注意：** 参数必须是非负整数。

## 使用示例

### 示例1：三角计算

```yan
# 计算直角三角形的斜边
```

## 注意事项

### 1. 角度制与弧度制
- 三角函数使用**弧度制**，不是角度制
- 如需使用角度，需先转换：弧度 = 角度 × π / 180

### 2. 对数函数限制
- 对数函数的参数必须**大于0**
- 对负数或0求对数会报错

### 3. 阶乘函数限制
- 阶乘函数的参数必须是**非负整数**
- 对负数或非整数求阶乘会报错

### 4. 数值精度
- 所有函数返回浮点数（除阶乘返回整数）
- 注意浮点数精度问题
