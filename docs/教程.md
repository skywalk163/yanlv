## 快速开始

### 安装

```bash
pip install yanlv
```

### 第一个程序

创建文件 `hello.yan`：

```yan
输出"你好，世界！"
```

运行：

```bash
yanlv run hello.yan
```

输出：

```
=> 你好，世界！
```

## 基础语法

### 注释

```yan
// 这是单行注释
# 这也是注释

定义变量x为10  // 行尾注释
```

### 语句

每个语句独占一行，或用分号分隔：


### 定义变量



1. **数字** - 整数和浮点数

3. **布尔值** - 真/假

## 高级特性

### 多轨制编程

言律支持在代码中嵌入Python、JavaScript、SQL代码：

```yan
// Python轨
Python轨
import numpy as np
arr = np.array([1, 2, 3, 4, 5])
mean = arr.mean()
print(f"平均值: {mean}")
结束Python轨

// JavaScript轨
JavaScript轨
const data = [1, 2, 3, 4, 5];
const sum = data.reduce((a, b) => a + b, 0);
console.log(`总和: ${sum}`);
结束JavaScript轨

// SQL轨
SQL轨
SELECT * FROM users
WHERE age > 18
ORDER BY name;
结束SQL轨
```

### 因果链语法

```yan
// 简单因果
下雨了，带伞。

// 条件因果
温度大于30，开空调。

// 多条件因果
温度大于30且湿度大于60，开启除湿模式。

// 状态变化因果
订单状态变为已付款，准备发货。
```

### 状态流语法

```yan
// 定义状态
初始状态为新建
订单状态为已付款
订单状态为已发货
终止状态为已完成

// 定义转换
订单状态变为已付款，准备发货
订单状态变为已发货，通知用户
当收到签收时，状态变为已完成
```

### 意合式调用

```yan
// 参数推断
定义变量x为10
加x 5  // 自动推断为加(x, 5)

// 链式调用
定义变量result为10加5乘2
输出result  // 30
```

## 实战示例

### 示例1：计算器

```yan
函数计算器参数a op b
  如果op等于"+"则
    返回a加b
  否则
    如果op等于"-"则
      返回a减b
    否则
      如果op等于"*"则
        返回a乘b
      否则
        如果op等于"/"则
          返回a除b
        否则
          返回"未知运算符"
        结束
      结束
    结束
  结束
结束

输出调用计算器参数10 "+" 5   // 15
输出调用计算器参数10 "-" 5   // 5
输出调用计算器参数10 "*" 5   // 50
输出调用计算器参数10 "/" 5   // 2.0
```

### 示例2：斐波那契数列

```yan
函数斐波那契参数n
  如果n小于等于1则
    返回n
  否则
    返回调用斐波那契参数n减1 加 调用斐波那契参数n减2
  结束
结束

// 输出前10个斐波那契数
循环10次执行
  输出调用斐波那契参数i
结束
```

### 示例3：学生成绩管理

```yan
// 定义学生数组
定义数组students为[]

// 添加学生函数
函数添加学生参数name score
  定义数组student为[name, score]
  添加student到students
结束

// 计算平均分函数
函数计算平均分
  定义变量total为0
  每个student在students执行
    设置total为total加student[1]
  结束
  返回total除长度students
结束

// 添加学生
调用添加学生参数"张三" 85
调用添加学生参数"李四" 92
调用添加学生参数"王五" 78

// 输出平均分
输出调用计算平均分  // 85.0
```

## 最佳实践

1. **使用有意义的变量名**
```yan
// 好的命名
定义变量学生姓名为"张三"
定义变量考试分数为85

// 不好的命名
定义变量x为"张三"
定义变量y为85
```

2. **添加注释**
```yan
// 计算圆的面积
定义变量半径为5
定义变量面积为3.14乘半径乘半径
输出面积
```

3. **模块化代码**
```yan
// 将功能封装为函数
函数计算面积参数半径
  返回3.14乘半径乘半径
结束

// 使用函数
输出调用计算面积参数5
```
