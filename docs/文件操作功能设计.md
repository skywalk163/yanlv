# 言律语言文件操作功能设计

## 概述

为言律语言添加文件操作功能，支持文件的读取、写入和路径操作。

---

## 功能设计

### 1. 文件读取

#### 1.1 读取整个文件

**语法：**
```
读取文件 文件路径 为 变量名
```

**功能：** 读取文件的全部内容到字符串变量。

**示例：**
```yan
读取文件 "data.txt" 为 内容
输出 内容
```

---

#### 1.2 读取文件行

**语法：**
```
读取行 文件路径 为 数组变量
```

**功能：** 读取文件的所有行到数组变量。

**示例：**
```yan
读取行 "data.txt" 为 行数组
输出 行数组
```

---

### 2. 文件写入

#### 2.1 写入文件

**语法：**
```
写入文件 文件路径 内容
```

**功能：** 将内容写入文件（覆盖模式）。

**示例：**
```yan
定义变量内容为"你好，世界！"
写入文件 "output.txt" 内容
```

---

#### 2.2 追加文件

**语法：**
```
追加文件 文件路径 内容
```

**功能：** 将内容追加到文件末尾。

**示例：**
```yan
追加文件 "log.txt" "新的日志记录"
```

---

### 3. 路径操作

#### 3.1 检查文件存在

**语法：**
```
文件存在 文件路径
```

**功能：** 检查文件是否存在，返回真或假。

**示例：**
```yan
文件存在 "data.txt"
```

---

#### 3.2 获取文件大小

**语法：**
```
文件大小 文件路径
```

**功能：** 获取文件大小（字节数）。

**示例：**
```yan
文件大小 "data.txt"
```

---

#### 3.3 获取文件名

**语法：**
```
文件名 完整路径
```

**功能：** 从完整路径中提取文件名。

**示例：**
```yan
文件名 "C:/Users/data.txt"    # 输出: "data.txt"
```

---

#### 3.4 获取目录名

**语法：**
```
目录名 完整路径
```

**功能：** 从完整路径中提取目录名。

**示例：**
```yan
目录名 "C:/Users/data.txt"    # 输出: "C:/Users"
```

---

## TokenType设计

```python
# 文件操作
READ_FILE = "READ_FILE"        # 读取文件
READ_LINES = "READ_LINES"      # 读取行
WRITE_FILE = "WRITE_FILE"      # 写入文件
APPEND_FILE = "APPEND_FILE"    # 追加文件
FILE_EXISTS = "FILE_EXISTS"    # 文件存在
FILE_SIZE = "FILE_SIZE"        # 文件大小
FILE_NAME = "FILE_NAME"        # 文件名
DIR_NAME = "DIR_NAME"          # 目录名
```
