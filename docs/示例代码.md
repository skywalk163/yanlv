## 算法实现

### 斐波那契数列

```yan
函数斐波那契参数n
  如果n小于等于1则
    返回n
  否则
    返回调用斐波那契参数n减1 加 调用斐波那契参数n减2
  结束
结束

// 输出前10个斐波那契数
输出"斐波那契数列:"
循环10次执行
  输出调用斐波那契参数i
结束
```

### 阶乘计算

```yan
函数阶乘参数n
  如果n等于0则
    返回1
  否则
    返回n乘调用阶乘参数n减1
  结束
结束

输出"5的阶乘:"
输出调用阶乘参数5  // 120
```

### 冒泡排序

```yan
函数冒泡排序参数arr
  定义变量n为长度arr
  循环n次执行
    循环n减i减1次执行
      定义变量j为i
      如果arr[j]大于arr[j加1]则
        定义变量temp为arr[j]
        设置arr[j]为arr[j加1]
        设置arr[j加1]为temp
      结束
    结束
  结束
  返回arr
结束

定义数组data为[64, 34, 25, 12, 22, 11, 90]
定义变量sorted为调用冒泡排序参数data
输出sorted
```

### 二分查找

```yan
函数二分查找参数arr target
  定义变量left为0
  定义变量right为长度arr减1
  
  当left小于等于right时
    定义变量mid为left加right除2取整
    
    如果arr[mid]等于target则
      返回mid
    否则
      如果arr[mid]小于target则
        设置left为mid加1
      否则
        设置right为mid减1
      结束
    结束
  结束
  
  返回-1
结束

定义数组arr为[1, 3, 5, 7, 9, 11, 13]
定义变量index为调用二分查找参数arr 7
输出"找到索引: "
输出index  // 3
```
