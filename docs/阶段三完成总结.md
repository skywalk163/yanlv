## 六、成果展示

### 1. 完整开发流程

```bash
# 1. 安装VS Code插件
code --install-extension yanlv-0.1.0.vsix

# 2. 创建言律项目
mkdir my-project
cd my-project
touch main.yan

# 3. 编写代码
# main.yan
定义变量x为10
输出x

# 4. 运行
yanlv run main.yan

# 5. 编译
yanlv compile main.yan --target python
yanlv compile main.yan --target javascript
```

### 2. 多轨制编程

```yan
# 数据处理流程
定义数组data为[1, 2, 3, 4, 5]

# Python处理
Python轨
import numpy as np
arr = np.array(data)
mean = arr.mean()
std = arr.std()
结束Python轨

# JavaScript可视化
JavaScript轨
const chart = {
  type: 'bar',
  data: data,
  mean: mean,
  std: std
};
console.log(chart);
结束JavaScript轨

# SQL存储
SQL轨
INSERT INTO statistics (data, mean, std)
VALUES (data, mean, std);
结束SQL轨
```
