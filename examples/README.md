## 示例详解

### 1. 冒泡排序 (`bubble_sort.yan`)

**难度：** 基础

**学习目标：**
- 变量定义：`定变量名是值`
- 函数定义：`定函数名是函参数：函数体`
- 循环结构：`对于变量从开始到结束：循环体`
- 条件判断：`若条件就：分支`

**核心代码：**
```yan
定冒泡排序是函列表：
  定长度是列表，长。
  
  对于i从0到长度减1：
    对于j从0到长度减i减2：
      若列表算j大列表算j加1就：
        列表、j、j加1，交换。
```

### 2. 口语化编程 (`colloquial_programming.yan`)

**难度：** 基础

**学习目标：**
- 询问式：`要是...就...`
- 建议式：`最好...`
- 祈使式：`请...`
- 疑问式：`...是否...？`
- 情境式：`当...的时候`

**核心代码：**
```yan
# 询问式
要是分数大等于90就印"优秀"。

# 建议式
最好先检查除数是否等于0。

# 祈使式
请先获取用户的邮箱。

# 疑问式
权限是否包含操作？

# 情境式
当订单状态是"新建"的时候：
  把状态改为"处理中"。
```

### 3. 因果链语法 (`causal_chain.yan`)

**难度：** 中级

**学习目标：**
- 简单因果：`条件，动作。`
- 多条件因果：`条件1、条件2，动作。`
- 状态因果：`状态变化，触发动作。`
- 链式因果：`数据，步骤1，步骤2，步骤3。`

**核心代码：**
```yan
# 简单因果
下雨了，带伞。

# 多条件因果
下雨了、下雪了、刮大风，带伞。

# 状态因果
订单状态变为已付款，准备发货。

# 链式因果
原始数据，验证格式，清洗数据，分析统计，生成报告。
```

### 4. 状态流语法 (`state_flow.yan`)

**难度：** 中级

**学习目标：**
- 状态定义：`状态名称：状态值1、状态值2`
- 状态转换：`对象·状态变为新状态。`
- 状态监听：`当对象·状态变为状态时：处理逻辑`
- 状态判断：`对象·状态为状态`

**核心代码：**
```yan
# 状态定义
状态订单状态：
  新建
  已付款
  已发货

# 状态转换
订单·状态变为已付款。

# 状态监听
当订单·状态变为已付款时：
  印"订单已付款，准备发货"。

# 状态判断
若订单·状态为新建就：
  处理订单。
```

### 5. 语境省略语法 (`context_omission.yan`)

**难度：** 中级

**学习目标：**
- 主题链：`对象：操作。`
- 主语省略：在主题链中省略对象引用
- 宾语省略：在操作链中省略参数
- 条件省略：累积条件判断

**核心代码：**
```yan
# 主题链
张三：
  姓名，印。
  年龄，印。
  城市，印。

# 方法链
数据：
  清洗。
  转换。
  分析。
  输出。

# 条件省略
分数：
  大于等于90，回"优秀"。
  大于等于80，回"良好"。
  大于等于60，回"及格"。
  不然，回"不及格"。
```

### 6. 多轨制语法 (`multi_track.yan`)

**难度：** 高级

**学习目标：**
- 数学轨：`算数学表达式。`
- Python轨：`{{Python代码}}`
- JavaScript轨：`[[JavaScript代码]]`
- SQL轨：`<<<SQL语句>>>`

**核心代码：**
```yan
# 数学轨
定计算圆面积是函半径：
  算π乘以半径的平方。

# Python轨
定数据分析是函数据：
  {{
import pandas as pd
df = pd.DataFrame(data)
return df.describe()
  }}

# JavaScript轨
定操作DOM是函元素ID、内容：
  [[
document.getElementById(elementId).innerHTML = content;
  ]]

# SQL轨
定查询用户是函用户ID：
  <<<
SELECT * FROM users WHERE id = {user_id}
  >>>
```

## 代码规范

### 命名规范

- 变量：使用中文名称，如 `定用户名是"张三"`
- 函数：使用动词+名词，如 `定计算面积是函参数：函数体`
- 状态：使用名词，如 `状态订单状态：新建、已付款`

### 缩进规范

- 使用2个空格缩进
- 块结构使用缩进定义，无需显式"结束"

### 注释规范

- 单行注释：`# 注释内容`
- 文档注释：在文件开头说明文件用途

## 常见问题

### Q: 为什么使用中文编程？

A: 中文编程更符合汉语使用者的思维习惯，降低学习门槛，提高代码可读性。

### Q: 言律语言与其他中文编程语言的区别？

A: 言律语言融合了四大核心语法（因果链、语境省略、状态流、意合式调用），基于认知科学设计，更符合中文深层认知特性。

### Q: 如何选择学习路径？

- 有基础：路径2（核心语法）
