📦 collections模块 - 高级数据结构

命名元组
创建具有命名字段的元组子类，让代码更清晰易读
  • 支持字段名称访问
  • 不可变数据结构
  • 内存效率高
点 = 命名元组('点', ['x', 'y']) p = 点(3, 4) print(p.x, p.y) # 3 4
计数器
用于计数可哈希对象的字典子类
  • 自动计数元素出现次数
  • 支持最常见的元素查询
  • 支持数学运算
c = 计数器('hello world') print(c.最常见(2)) # [('l', 3), ('o', 2)]
双端队列
支持在两端快速添加和删除元素
  • O(1)时间复杂度的两端操作
  • 支持最大长度限制
  • 线程安全
q = 双端队列([1, 2, 3]) q.左端添加(0) q.右端添加(4) # [0, 1, 2, 3, 4]
