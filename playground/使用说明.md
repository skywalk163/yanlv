# 言律语言 Playground 服务使用说明

## 问题解决

### 原始问题
```
curl: (7) Failed to connect to 127.0.0.1 port 5000 after 2037 ms: Could not connect to server
```

### 问题原因
1. Flask的debug模式使用了重载器（reloader），可能导致连接问题
2. 服务启动后需要等待几秒钟才能接受连接

### 解决方案
修改了 `server.py`，禁用debug模式并使用threaded模式：
```python
app.run(host='127.0.0.1', port=5000, debug=False, threaded=True)
```

## 注意事项

1. **端口占用**：如果5000端口被占用，可以修改 `server.py` 中的端口号
2. **防火墙**：Windows防火墙可能阻止连接，需要允许Python访问网络
3. **启动时间**：服务启动后需要等待2-3秒才能接受连接
4. **生产环境**：不要在生产环境使用Flask开发服务器，应使用WSGI服务器（如gunicorn）

## 故障排除

### 问题1: 无法连接
**症状：**
```
curl: (7) Failed to connect to 127.0.0.1 port 5000
```

**解决：**
1. 检查服务是否启动：`netstat -ano | findstr :5000`
2. 检查进程是否运行：`tasklist | findstr python`
3. 重启服务：停止旧进程，重新启动

### 问题2: 端口被占用
**症状：**
```
OSError: [Errno 10048] Address already in use
```

**解决：**
1. 查找占用进程：`netstat -ano | findstr :5000`
2. 停止占用进程：`taskkill /F /PID <进程ID>`
3. 或修改端口号

### 问题3: 防火墙阻止
**症状：**
连接超时或被拒绝

**解决：**
1. 打开Windows防火墙设置
2. 允许Python通过防火墙
3. 或临时关闭防火墙测试
