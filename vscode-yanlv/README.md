# 言律语言 VS Code 插件

为言律编程语言提供VS Code支持，包括语法高亮、自动补全、错误诊断等功能。

## 功能特性

### 语法高亮
- 关键字高亮
- 字符串高亮
- 数字高亮
- 注释高亮
- 运算符高亮
- 函数名高亮

### 自动补全
- 关键字补全
- 内置函数补全
- 数学函数补全
- 运算符补全
- 代码片段补全

### 错误诊断
- 未闭合块检测
- 语法错误检测
- 变量定义检查
- 函数定义检查

### 代码片段
- `定义变量` - 定义一个变量
- `定义数组` - 定义一个数组
- `如果` - 条件语句
- `如果否则` - 条件否则语句
- `循环` - 循环语句
- `当` - 当循环
- `函数` - 函数定义
- `调用` - 函数调用
- `输出` - 输出语句
- `尝试` - 异常处理

## 安装

1. 安装VS Code
2. 克隆此仓库
3. 运行 `npm install`
4. 运行 `npm run compile`
5. 在VS Code中按F5启动调试

## 使用

1. 创建或打开 `.yan` 或 `.yanlv` 文件
2. 开始编写言律代码
3. 使用自动补全和代码片段提高效率

## 示例

```yan
// 定义变量
定义变量x为10
定义变量y为20

// 条件语句
如果x大于y则
  输出"x大于y"
否则
  输出"y大于等于x"
结束

// 循环
循环5次执行
  输出i
结束

// 函数
函数加法参数a b
  输出a加b
结束
调用加法参数10 20
```

## 命令

- `yanlv.compile` - 编译言律代码
- `yanlv.run` - 运行言律代码

## 配置

在 `settings.json` 中可以配置：

```json
{
  "yanlv.enableDiagnostics": true,
  "yanlv.enableCompletion": true
}
```

## 开发

### 构建
```bash
npm run compile
```

### 监听模式
```bash
npm run watch
```

### 测试
```bash
npm run test
```
